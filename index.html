02 / The game

Run a lab. Grow things.

You work in a small lab. Pull supplies from the dispenser, swab spores onto agar plates, cut the cultures apart, and move clean pieces into grain bags. Dirty air and bacteria will ruin a plate, so you watch the contamination risk before you seal anything.

I'm one developer and I've been coding since I was 8. The demo is free.
